# Day-1--18_Among_us-_Dimas_Rafi_Ferdianto
Day 1 TIK Mengajar - Workshop Mempelajari Git &amp; Github

Nama Lengkap : Dimas Rafi Ferdianto

Penjelasan Repository :
Repository ini adalah tempat penyimpanan dan dokumentasi daring resmi untuk mengumpulkan seluruh materi, catatan pembelajaran, dan tugas selama mengikuti kegiatan Day 1 Proyek Workshop.

Tujuan & Kegunaan Repository :
1. Mempelajari dan melatih penggunaan GitHub untuk mengelola dokumentasi proyek secara publik dan transparan.
2. Menyimpan rangkuman serta catatan pembelajaran materi Git, GitHub, dan Prompt Engineering agar mudah diakses kembali.
3. Melatih keterampilan menyusun dokumentasi terstruktur menggunakan format file README.md.

Rangkuman Materi :
- Workshop membawakan materi utama "Building with AI, Managing Change with GitHub".
- Prompt Engineering: Mengajarkan teknik merancang masukan/instruksi (Role, Task, Context, Format) yang spesifik ke AI agar menghasilkan output kode/solusi yang akurat.
- Git & GitHub: Git bekerja secara lokal untuk melacak riwayat perubahan file (Working Directory -> Staging Area -> Repository), sedangkan GitHub berfungsi sebagai platform cloud untuk menyimpan repository Git secara online dan memfasilitasi kolaborasi.

Poin - Poin Penting atau Pengetahuan Baru :
1. Perbedaan mendasar antara Git (VCS lokal di komputer) dan GitHub (platform hosting repository online).
2. Pentingnya memberikan context yang jelas pada prompt AI agar kode atau proyek aplikasi web yang dibuat sesuai dengan spesifikasi yang dibutuhkan.
3. Alur kerja manajemen versi file serta pengkonfigurasian SSH Key untuk autentikasi keamanan antara perangkat lokal dan GitHub.

Pendapat Pribadi Mengenai Workshop:
Penyampaian materi mengenai kombinasi AI dan GitHub memberikan gambaran jelas tentang cara mengelola proyek pengembangan perangkat lunak secara efektif dan profesional di industri.
